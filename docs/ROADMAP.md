# Advanced Extension Roadmap

The current release is complete as a portfolio project. These are intentionally
documented as future research directions rather than unfinished requirements.

1. Convolution and pooling kernels
2. BatchNorm and LayerNorm
3. Attention / transformer blocks
4. mixed-precision kernels
5. vectorised im2col convolution
6. GPU backend
7. automatic graph visualisation
8. ONNX-style model export

The project already demonstrates the core framework architecture, automatic
differentiation, optimisation, training and evaluation.
